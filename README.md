# 사탕 받기

손바닥을 편 채 떨어지는 것을 따라가다가, 주먹을 쥐어 사탕만 잡는 브라우저 게임. 유령은 잡으면 안 된다. 카메라나 마우스로 할 수 있다.

## 준비물

- PC와 Chrome 브라우저
- [Git](https://git-scm.com/)과 [Python 3](https://www.python.org/downloads/)
- 카메라 모드만: 웹캠과 인터넷 연결 (손 인식 모델을 인터넷에서 받는다)

## 실행

터미널에서 아래 명령을 차례로 입력한다.

```
git clone https://github.com/jinwonnie00/workshop-01.git
cd workshop-01
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 연다. 끝낼 때는 터미널에서 `Ctrl+C`를 누른다.

`index.html`을 더블클릭해서 열면 안 된다. 카메라는 `localhost`나 HTTPS에서만 켜진다.

## 조작법

시작 화면에서 버튼을 하나 고른다.

| 버튼 | 조작 |
|---|---|
| `카메라로 시작` | 카메라 권한을 허용하고 준비될 때까지 기다린다. 카메라에 **한 손**을 손바닥이 보이게 펴고 좌우로 움직인다. 사탕이 손에 왔을 때 **주먹을 쥐면** 잡는다. 손이 안 보이면 게임이 멈추고, 다시 보이면 이어진다. |
| `마우스로 시작` | 마우스를 좌우로 움직이고, 사탕이 손에 왔을 때 **왼쪽 버튼을 누르면** 잡는다. |

- 손을 편 채로는 아무것도 잡히지 않는다. 사탕도 유령도 손을 지나간다.
- 주먹을 쥐는 **순간**에만 잡힌다. 쥔 채로 있으면 더 잡히지 않으니, 다시 잡으려면 손을 폈다가 쥔다. (마우스는 버튼을 뗐다가 누른다)
- 쥐는 순간 손 위치에 있던 것은 모두 잡힌다. 사탕 옆에 유령이 붙어 있으면 조심한다.

## 규칙

- 사탕을 잡으면 1점을 얻는다.
- 유령을 잡으면 목숨이 하나 줄어든다. 목숨은 3개이고, 0이 되면 게임이 끝난다.
- 사탕이나 유령을 잡지 않고 보내도 감점은 없다.
- 시간이 지날수록 빨라지고 유령이 많아진다.
- 끝 화면에서 `다시 하기`를 누르면 같은 조작 방식으로 새 판을 시작한다.

## 소리

- 게임을 하는 동안 배경 음악이 반복해서 흐른다. 손을 놓쳐 게임이 멈춰도 음악은 계속된다.
- 유령을 잡으면 유령 소리가 난다.
- 게임이 끝나면 배경 음악이 작아지며 멈추고, 긴 유령 소리가 난다.
- 소리는 시작 버튼을 누른 뒤부터 난다. 시작 화면과 끝 화면에서는 배경 음악이 나지 않는다.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| `python3`를 찾을 수 없다고 나온다 | Python 3을 설치한다. Windows에서는 `python -m http.server 8000`으로 실행한다. |
| 포트 8000을 이미 쓰고 있다고 나온다 | `python3 -m http.server 8001`로 실행하고 `http://localhost:8001` 을 연다. |
| 카메라로 시작하면 오류 문구가 뜬다 | 브라우저의 카메라 권한과 인터넷 연결을 확인한다. 안 되면 `마우스로 시작`을 누른다. |
| `손을 보여주세요`가 자주 뜬다 | 카메라에서 50cm쯤 떨어져 밝은 곳에 앉고, 손바닥을 카메라 쪽으로 향한 채 손목까지 화면 안에 들어오게 한다. 안 되면 `마우스로 시작`을 누른다. |
| 소리가 안 난다 | 컴퓨터 소리 크기와, 브라우저 탭이 음소거되어 있지 않은지 확인한다. 소리는 시작 버튼을 누른 뒤부터 난다. 소리가 안 나도 게임은 그대로 할 수 있다. |
| 주먹을 쥐어도 잡히지 않는다 | 손바닥이 카메라를 향한 채로 네 손가락을 꽉 접는다. 손을 옆으로 돌리면 손가락이 가려져 주먹으로 인식되지 않을 수 있다. 화면의 손 그림이 주먹으로 바뀌는지 보면서 연습한다. |
